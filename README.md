# 🛡️ CyberShield

## Présentation du projet
CyberShield est un site web de sensibilisation à la cybersécurité.
Il aide les utilisateurs à protéger leurs données personnelles
et à adopter de bonnes habitudes sur Internet.

## Objectifs
- Comprendre les risques sur Internet.
- Reconnaître les tentatives de phishing.
- Utiliser des mots de passe sécurisés.
- Protéger ses comptes et ses données personnelles.

## Technologies utilisées
- HTML5 : structure du site.
- CSS3 : design et mise en page.
- Git : gestion des versions.
- GitHub : hébergement du code source.

## Contenu du site
- Le phishing
- Les mots de passe
- La cybersécurité
- Le Wi-Fi public
- La double authentification
- Les mises à jour

## Auteur
Projet pédagogique réalisé dans le cadre de l'apprentissage du développement web.
